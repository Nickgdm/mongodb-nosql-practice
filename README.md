Projeto educacional para praticar consultas e operações de pesquisa no MongoDB utilizando conjuntos de dados de estudantes e professores.

## Sobre o projeto

O repositório contém dados de exemplo em JSON e consultas para exercitar filtros, ordenação, projeção de campos e agregações.

## Objetivos

- Filtrar e ordenar documentos.
- Pesquisar valores com expressões regulares.
- Projetar campos específicos.
- Agrupar e contabilizar documentos com operações de agregação.

## Tecnologias e ferramentas

- MongoDB
- JavaScript para consultas
- Arquivos JSON para dados de exemplo

## Pré-requisitos

- MongoDB instalado ou acesso a uma instância MongoDB.
- Mongo Shell (`mongosh`) ou ferramenta compatível.

## Como executar

1. Inicie ou acesse uma instância MongoDB.
2. Importe os arquivos JSON para coleções apropriadas ou utilize-os como referência para inserir os documentos.
3. Abra `queries-mongodb.js` e execute as consultas no contexto do banco e das coleções esperadas.
4. Confira os resultados e adapte os nomes do banco e das coleções à configuração local.

## Estrutura do projeto

```text
atividade-NoSQL/
├── estudantes.json
├── professores.json
├── queries-mongodb.js
└── README.md
```

## Desafios práticos

O exercício aborda ordenação, filtros por curso, nota e cargo, pesquisa textual, seleção de campos e agregação para contabilizar estudantes por curso.

## Boas práticas

- Separar os dados de exemplo das consultas.
- Utilizar arquivos JSON para facilitar a reprodução do exercício.
- Organizar as consultas por objetivo.
- Conferir os nomes do banco e das coleções antes de executar.

## Aprendizados

A atividade permite praticar consultas NoSQL com MongoDB, incluindo filtros, ordenação, expressões regulares, projeção de campos e pipelines de agregação. Também reforça a importância de compreender a estrutura dos documentos e validar os resultados das consultas.

## Considerações finais

Este repositório contém material de estudo. Os nomes do banco e das coleções devem corresponder ao contexto esperado pelas consultas durante a execução.
